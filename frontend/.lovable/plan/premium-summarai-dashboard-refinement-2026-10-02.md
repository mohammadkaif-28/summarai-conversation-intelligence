# Premium SummarAI Dashboard Refinement

## Overview
Refine the existing SummarAI workspace using the selected premium glass dashboard direction while keeping all current analysis, history, download, theme, and API behaviors intact.

## What will change
- Add a restrained cool-blue ambient glow, deeper slate surfaces, soft glass layering, and more generous spacing.
- Upgrade the transcript workspace with a subtle gradient edge, recessed textarea, warm placeholder, and an in-field character counter that turns amber near the limit.
- Restyle the primary analysis action with a deep blue-to-purple gradient, crisp high-contrast text, and a restrained glow that strengthens on hover.
- Refine the ready state with a larger illuminated brain mark, the requested direct copy, and a working “View Example Summary” action that fills the transcript with an example rather than displaying fake results.
- Polish the sidebar with a clearer translucent active state, metallic brand mark, quieter footer treatment, and amber pulsing offline/checking status that becomes green when connected.
- Improve processing presentation without implying completion: show the current rotating activity label only, with all phases visibly presented as active processing rather than completed milestones.
- Refine results into clearly separated summary, key points, action items, decisions, and topics, including a subtle “Generated by SummarAI” context label.
- Apply consistent 300ms easing, softer 12px+ corners, visible focus states, and accessible contrast across desktop and mobile layouts.

## Technical details
- Extend semantic OKLCH tokens and reusable utilities in the global design system; avoid hardcoded colors in page code.
- Update the existing shared button variant for consistent corner radius and transition behavior.
- Keep all FastAPI response handling unchanged and continue rendering only real backend results.
- Preserve the current responsive sidebar/drawer structure and all error, retry, save, delete, copy, and download behavior.
- Verify the updated interface in the live preview at desktop and mobile widths and confirm the generated build remains clean.
